# Code of Conduct

We want this project to be a welcoming and constructive place for everyone.

Contributors are expected to:

- Be respectful and assume good intent.
- Focus feedback on the code and user impact.
- Avoid harassment, discrimination, personal attacks and publishing private data.
- Report unacceptable behavior privately to the maintainer through GitHub.

Maintainers may remove contributions or restrict participation when behavior violates these expectations.
